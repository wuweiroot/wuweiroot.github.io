    SMI注册与触发流程

    March 13, 2026
    • 同步 SMI：仅指通过 EFI_SMM_COMMUNICATE_PROTOCOL 发起的、携带数据缓冲区的 SMI 通过 GUID 派发。
    • 异步 SMI：包括所有硬件触发（GPI、电源按钮、定时器、USB）以及软件端口触发的 SMI（如 SwSmi）。
    • 软件 SMI 虽由软件写入触发，但属于异步 SMI，其派遣函数中需要通过遍历 CPU 状态来定位触发源，因为硬件未记录 CPU 编号。

    概述#

    
上层驱动 (EC)
   │
   ├─ 通过 gEfiSmmGpiDispatch2ProtocolGuid->Register()
   │     │
   │     └─ FchSmmGpiDispatch2RegisterWorker
   │           ├─ 创建 FCH_SMM_GPI_NODE 并加入 HeadFchSmmGpiNodePtr
   │           ├─ 硬件使能GPI中断
   │           └─ (若调试协议存在) mSmiHandlerProfileProtocol->RegisterHandler()
   │                   └─ 创建调试 SMI_HANDLER，加入 mHardwareSmiEntryList 对应的 SMI_ENTRY
   │
   └─ (SMM核心) SmiHandlerRegister(FchSmmDispatchHandler, NULL, ...)
         └─ 创建核心 SMI_HANDLER，加入 mRootSmiEntry.SmiHandlers

SMI 触发
   │
   └─ SmmEntryPoint -> SmiManage
         ├─ 遍历 mRootSmiEntry 下的所有核心 SMI_HANDLER
         │     └─ 调用 FchSmmDispatchHandler
         │           └─ 遍历 FchSmmDispatcherTable
         │                 └─ 调用 FchSmmGpiDispatcher
         │                       └─ 遍历 HeadFchSmmGpiNodePtr，找到匹配节点
         │                             └─ 调用 EcSmiHandler
         └─ (可能同时) 调试层记录不参与中断分发，仅用于信息查询

      • 创建GPI SMI 节点 并且加入GPI SMI 链表 HeadFchSmmGpiNodePtr

      • RETURN_ADDRESS(L)：安全宏，仅 L=0 有效，返回地址；否则返回空；
      • _ReturnAddress()：编译器内置，获取直接调用者的返回地址；

                                                    mSmiHandlerProfileProtocol,
                                                    &gEfiSmmGpiDispatch2ProtocolGuid,
                                                    DispatchFunction,  //回调函数
                                                    (PHYSICAL_ADDRESS)(UINTN)RETURN_ADDRESS (0),  //

                                                    )

    SMM触发入口 SmmEntryPoint#

    SmiManage#

    Smi中断入口 判断 HandlerType

    • HandlerType == NULL
      • SmiEntry = &mRootSmiEntry;
    • HandlerType != NULL
      • SmmCoreFindSmiEntry
      • 检查同GUID类型的 mSmiEntryList 并且取出
    • 通过SmiEntry找到SmiHandler，遍历执行 SmiHandler->Handler
    CPU 因 SMI 进入 SMM
    │
    ▼
SmmEntryPoint()
    ├─ 更新 SMST、执行钩子
    ├─ 处理同步 SMI（Communication Buffer）
    │      └─ SmiManage(HandlerType = GUID, ...)
    │             └─ 在 mSmiEntryList 中找到对应 GUID 的 SMI_ENTRY
    │                    └─ 遍历其 SmiHandlers，调用处理程序（如通信协议回调）
    │
    └─ 处理异步 SMI
           └─ SmiManage(NULL, NULL, NULL, NULL)
                  └─ 使用 mRootSmiEntry（根入口）
                         └─ 遍历其 SmiHandlers
                                └─ 调用 FchSmmDispatchHandler（之前注册的）
                                       └─ 遍历 FchSmmDispatcherTable
                                              └─ 调用 FchSmmGpiDispatcher
                                                     └─ 遍历 HeadFchSmmGpiNodePtr
                                                            └─ 调用 EcSmiHandler
